# Validation

General availability requires deterministic release construction, Python 3.11 through 3.14 conformance, exact schemas, checksums, attestations, updater identity, clean enrollment, update and rollback behavior, and the Codex/macOS workflow scenario.

Claude live-client validation is pending follow-up and is not a v2.0.0 release gate. The first authenticated Gurzu engineer integrating Claude on macOS or Linux records their identity, operating system, exact client version, explicit invocation, read-only planning, approved implementation, single-writer behavior, tests, applicable review, bounded actions, secret avoidance, and the `Accomplished`/`Next step` handoff.

No validation code or acceptance rule inspects organization 2FA. Validation is independent of consumer products and uses product-neutral standard-library fixtures only.
